## 📖 About

This repository is my personal roadmap for mastering Python beyond the basics. It contains **concept-wise notes and code**, plus **hands-on projects** that apply those concepts in practical, real-world scenarios.

Whether you're revisiting Python fundamentals with a professional lens or leveling up from intermediate to advanced, this repo is meant to be a structured, growing reference.

## 📚 Topics Covered

| Category | Topics |
|---|---|
| **Error Handling** | `try` / `except` / `else` / `finally`, exception types |
| **File Handling** | detecting, reading, writing, copying, moving, deleting files |
| **Modules** | importing & organizing code across files |
| **OOP** | classes & objects, class variables, inheritance (single/multilevel/multiple), method overriding, method chaining, `super()`, abstract classes, objects as arguments, duck typing |
| **Functional / Modern Python** | walrus operator, functions as variables, higher-order functions, `lambda`, `sort`, `map`, `filter`, `reduce`, list & dict comprehensions, `zip`, `if __name__ == '__main__'` |
| **Concurrency** | `time` module, threading, daemon threads, multiprocessing |
| **GUI (Tkinter)** | windows, labels, buttons, entryboxes, checkboxes, radio buttons, scale, listbox, messagebox, colorchooser, text area, file dialogs, menubar, frames, tabs, grid layout, progress bar, canvas, keyboard/mouse events, drag & drop, animations |
| **Deployment** | running via command prompt, `pip`, converting `.py` to `.exe` |

*(Starting point: exception handling onward — earlier basics like variables, loops, and data types are assumed knowledge.)*

## ▶️ How to Use This Repo

1. Clone the repository
   ```bash
   git clone https://github.com/<your-username>/PyMastery.git
   cd PyMastery
   ```
2. Navigate to any concept or project folder
3. Run the Python file
   ```bash
   python filename.py
   ```
